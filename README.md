Indonesia in Numbers — a national statistics site for the Republic of Indonesia. Eight pages (Overview, Population, Economy, Prices, Labour, Regions, Data tables, Sources) cover 281.6 million people, a US$1.40 trillion economy, inflation, work and the 38 provinces, with charts drawn in code and every figure carrying its official source and year (BPS Statistics Indonesia, the World Bank and others). Plain static files under app/ — no build step, no framework, no network loads; it works fully offline on desktop and phone. The Data tables page searches and filters all 39 headline indicators; the Regions page sorts its province table by any column.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a browser (or open app/index.html directly)
```
